# Backyard Sundays — Fort City Valley Gardens

One-page gallery for the Backyard Sundays event, 22nd November 2026.

The flyer is the hero; the 12 photos sit in a responsive grid with a tap-to-zoom
viewer (arrow keys and swipe-free prev/next). Images are served from the
DeryAccount public file store, so updating a photo means changing its URL in the
`photos` array near the bottom of `index.html`.
